# HelloConstraint

A simple Android app built in Java that demonstrates interactive UI elements and responsive layouts using **ConstraintLayout**. Based on the *Android Developer Fundamentals* course material.

## Features

- **Toast** button that shows a short pop-up message
- **Count** button that increases the counter and changes its own color depending on whether the number is even or odd
- **Zero** button that resets the counter to 0. It starts gray, turns a highlight color once the counter is above zero, and goes back to gray when reset
- Buttons are aligned to the left of the counter and spaced evenly between its top and bottom edges using constraints
- Separate layouts for **portrait**, **landscape** (`layout-land`) and **tablets** (`layout-xlarge`)
